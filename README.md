# Task Tracker

Учебный проект по дисциплине «Практический курс веб разработки: React, TypeScript, Node и Supabase».

## О проекте

## Основной сценарий
Task Tracker помогает пользователю организовать выполнение учебных, рабочих и повседневных задач. Пользователь может добавлять новые задачи, указывать сроки их выполнения и уровень важности (приоритет), изменять статусы прогресса («К выполнению», «В работе», «Выполнено»), а также фильтровать задачи и оперативно находить актуальные или просроченные записи.

## Стек технологий
- **Фронтенд:** React 19, TypeScript, Vite
- **Стилизация:** CSS3 (семантическая верстка, адаптивный дизайн)
- **Среда выполнения и сборщик:** Node.js (v24.21.0), npm
- **Контроль версий:** Git, GitHub
- **Будущий стек (последующие ЛР):** Supabase (PostgreSQL, Auth), Node.js API

## Версия Node.js
В проекте зафиксирована версия Node.js: `24.21.0` (см. файл `.node-version`).

## Запуск проекта

Из корня скачанного репозитория:

```bash
cd frontend
npm ci
npm run dev
```

После запуска в терминале отобразится локальный адрес сервера разработки (по умолчанию `http://localhost:5173/`).

---

## Проверка сборки и preview

Остановите сервер разработки сочетанием `Ctrl + C`. Затем выполните в каталоге `frontend`:

```bash
npm run build
npm run preview
```

Команда `npm run build` выполняет проверку типов TypeScript (`tsc -b`) и собирает production-билд в директорию `frontend/dist`. Команда `npm run preview` запускает локальный сервер для предпросмотра собранного приложения.

## Текущее состояние приложения (Лабораторная работа 1)
- Развёрнут базовый каркас приложения на React + TypeScript с помощью Vite.
- Реализован начальный экран с семантической структурой: заголовок приложения, краткое описание и блок-заглушка для будущего списка задач.
- Удалены демонстрационные файлы и логотипы стартового шаблона Vite, настроен русский язык (`lang="ru"`).
- Настроена строгая проверка типов TypeScript (`strict: true`).
- Создана единая структура репозитория `course-app` с заделом под будущие модули `backend` и `supabase`.

## Текущие ограничения
На этапе ЛР 1 приложение отображает статический начальный экран и информационную заглушку. Формы создания/редактирования задач, интерактивное управление состоянием, маршрутизация (роутинг), хранение данных в Supabase и серверное API на Node.js будут добавлены в последующих лабораторных работах согласно плану курса.
