# Expense Tracker

Учебный проект по дисциплине «Практический курс веб разработки: React, TypeScript, Node и Supabase».

## О проекте
- **Тема:** Expense Tracker (учёт личных расходов, категорий трат, контроль бюджета)
- **Студент:** Плешкан Александр Александрович

## Основной сценарий
Expense Tracker предназначен для ведения личной бухгалтерии и учёта повседневных трат. Пользователь может фиксировать расходы и доходы, распределять операции по категориям (продукты, жильё, транспорт, развлечения и др.), отслеживать общий баланс за текущий месяц и анализировать динамику расходов для контроля личного бюджета.

## Стек технологий
- **Фронтенд:** React 19, TypeScript, Vite
- **Стилизация:** CSS3 (семантическая верстка, карточный дизайн, адаптивность)
- **Среда выполнения и сборщик:** Node.js (v24.21.0), npm
- **Контроль версий:** Git, GitHub
- **Будущий стек (последующие ЛР):** Supabase (PostgreSQL, Auth), Node.js API

## Версия Node.js
В проекте зафиксирована версия Node.js: `24.21.0` (см. файл `.node-version`).

## Запуск проекта

Из корня репозитория:

```bash
cd frontend
npm ci
npm run dev
```

После запуска в терминале отобразится локальный адрес сервера разработки (по умолчанию `http://localhost:5173/`).

---

## Проверка сборки и preview

Остановите сервер разработки сочетанием `Ctrl + C`. Затем выполните в каталоге `frontend`:

```bash
npm run build
npm run preview
```

Команда `npm run build` выполняет проверку типов TypeScript (`tsc -b`) и собирает production-билд в директорию `frontend/dist`. Команда `npm run preview` запускает локальный сервер для предпросмотра собранного приложения.

## Текущее состояние приложения (Лабораторная работа 1)
- Развёрнут базовый каркас приложения на React + TypeScript с помощью сборщика Vite.
- Реализован начальный экран финансового трекера: заголовок приложения, карточки сводки бюджета (баланс, доходы, расходы) и блок истории транзакций со заглушкой (*empty state*).
- Удалены демонстрационные файлы и логотипы стартового шаблона Vite, настроен русский язык (`lang="ru"`).
- Настроена строгая проверка типов TypeScript (`strict: true`).
- Организована единая структура репозитория `course-app` с заделом под будущие модули `backend` и `supabase`.

## Текущие ограничения
На этапе ЛР 1 приложение отображает статический интерфейс и информационные заглушки. Форма добавления операций, интерактивный выбор категорий, расчёт сумм в реальном времени, валидация полей, хранение данных в Supabase и серверное API на Node.js будут добавлены в последующих лабораторных работах согласно плану курса.
