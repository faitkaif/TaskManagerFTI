# Прогресс разработки: Лабораторная работа 1

## Тема проекта
**Task Tracker** — система управления личными задачами, сроками и приоритетами.

## Результат работы
Подготовлена воспроизводимая основа веб-приложения на React 19 + TypeScript + Vite. Настроен начальный экран приложения с семантической вёрсткой, базовыми стилями и заглушкой для списка задач. Организован единый Git-репозиторий `course-app` со структурой для дальнейшего расширения (клиентский пакет `frontend`, будущие `backend` и `supabase`).

6. **Проверка чистоты репозитория и запуска из чистой копии:**
