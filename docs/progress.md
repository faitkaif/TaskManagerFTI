# Прогресс разработки: Лабораторная работа 1

## Тема проекта
**Expense Tracker** — система учёта личных финансов, расходов, категорий трат и контроля бюджета.

## Результат работы
Подготовлена воспроизводимая основа веб-приложения на React 19 + TypeScript + Vite. Настроен начальный экран финансового трекера с семантической вёрсткой, базовыми стилями, карточками сводки бюджета и заглушкой для истории транзакций. Организован единый Git-репозиторий `course-app` со структурой для дальнейшего расширения (клиентский пакет `frontend`, будущие `backend` и `supabase`).

## Шаги проверки работы
1. **Проверка версий окружения:**
   - Node.js: `v24.21.0` (зафиксирована в `.node-version`)
   - npm: `11.19.0`
   - Git: `2.54.0`
2. **Проверка запуска dev-сервера:**
   - Выполнен переход в `frontend` и запуск `npm run dev`. Сервер успешно стартует на локальном порту без ошибок в консоли терминала и браузера.
3. **Проверка начального экрана:**
   - В браузере корректно отображается заголовок приложения «Expense Tracker», карточки сводки (баланс, доходы, расходы) и карточка-заглушка «Список расходов пока пуст». Стартовые логотипы Vite/React и демонстрационный счётчик полностью удалены.
4. **Проверка строгой типизации TypeScript:**
   - Проведён тест строгой типизации конфигурационного объекта `config` (интерфейс `AppConfig`). При подстановке некорректного типа данных команда `npm run build` выдаёт ошибку типизации TypeScript. При корректных типах сборка проходит успешно.
5. **Проверка сборки (Production build) и preview:**
   - Команда `npm run build` (`tsc -b && vite build`) успешно компилирует проект в директорию `frontend/dist`.
   - Команда `npm run preview` успешно открывает оптимизированную production-версию.
6. **Проверка чистоты репозитория и запуска из чистой копии:**
   - Файлы `node_modules` и `dist` исключены из Git через `.gitignore`. Команда `npm ci` и последующий билд воспроизводятся с нуля.
